Bundled fonts (self-hosted so client sites make no calls to Google Fonts).

Cormorant Garamond, Lora, Jost and Nunito: variable fonts, Latin subset, woff2.
All four are licensed under the SIL Open Font License 1.1. The licence text for
each is in the OFL-*.txt file beside it. Font files come from the Fontsource
packages (@fontsource-variable/*).

Files are referenced only from includes/class-twd-sk-packs.php (the font list).
